# Bnjs7<3de

Esta carpeta es autocontenida. Extrae el ZIP y abre `index.html` directamente; no requiere servidor, Node, conexión a internet ni archivos externos para mostrar la infografía.

## Contenido

- `index.html`: infografía autónoma con datos e imágenes incrustados.
- `data.json`: datos estructurados del perfil y clasificaciones.
- `images/`: 139 imágenes originales guardadas localmente.
- `checkpoint.json`: evidencia de la extracción página por página.
- `pokemon-classifications.json` y `unite-db-classifications.json`: catálogo de 103 clasificaciones de UniteDB.
- `manifest.json`: resumen de integridad de la entrega.

La infografía contiene 97 Pokémon. El HTML incorpora las imágenes usadas por la interfaz para que sus tarjetas, filtros, iconos y avatar sigan funcionando al compartir la carpeta comprimida.
