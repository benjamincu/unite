# shoJau

Perfil de UniteAPI: https://uniteapi.dev/es/p/13936631059660305309

Esta carpeta es autocontenida. Extrae el ZIP y abre `index.html` directamente; no requiere servidor, Node, conexión a internet ni archivos externos para mostrar la infografía.

## Contenido

- `index.html`: infografía autónoma, con datos e imágenes incrustados.
- `data.json`: perfil, estadísticas All-Time, 96 Pokémon y clasificación UniteDB.
- `images/`: 140 recursos originales descargados.
- `checkpoint.json`: checkpoints de la extracción.
- `pokemon-classifications.json` y `unite-db-classifications.json`: catálogo y fuente de clasificaciones.
- `manifest.json`: datos de integridad de la entrega.
