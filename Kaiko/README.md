# Kaīko

Esta carpeta es autocontenida. Extrae el ZIP y abre index.html directamente; no requiere servidor, Node, conexión a internet ni archivos externos para mostrar la infografía.

## Contenido

- index.html: infografía autónoma con datos e imágenes incrustados.
- data.json: datos estructurados del perfil.
- images/: imágenes locales originales.
- checkpoint.json: progreso y evidencia de la extracción.
- pokemon-classifications.json y unite-db-classifications.json: roles y tipos de ataque de UniteDB.
- manifest.json: resumen de la entrega.

La infografía contiene 96 Pokémon y 138 recursos descargados.
